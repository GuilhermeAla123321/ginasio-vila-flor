# Modelos 3D dos equipamentos

Os modelos GLB são carregados pelo visualizador `js/equipment-3d.js` quando o utilizador seleciona **Mostrar equipamento**. Todos os modelos são locais e não dependem de serviços externos.

| Modelo | Equipamento na aplicação |
|---|---|
| `passadeira.glb` | Passadeira |
| `bicicleta-spinning.glb` | Bicicleta |
| `eliptica.glb` | Elíptica |
| `remo.glb` | Máquina de Remo |
| `smith-machine.glb` | Smith Machine |
| `polia-dupla.glb` | Polia Multifuncional |
| `abdutor-adutor.glb` | Máquina Abdutora (modelo abdutor/adutor) |
| `shoulder-press.glb` | Prensa de Ombros |
| `pec-fly.glb` | Peck Deck |
| `leg-press.glb` | Leg Press |
| `extensao-pernas.glb` | Cadeira Extensora |
| `leg-curl.glb` | Mesa Flexora |
| `suporte-halteres.glb` | Peso Livre — suporte |
| `banco-ajustavel.glb` | Peso Livre — banco ajustável |
| `haltere-redondo.glb` | Peso Livre — haltere redondo |
| `haltere-hexagonal.glb` | Peso Livre — haltere hexagonal |

O serviço de cache da PWA deve ser atualizado sempre que forem adicionados ou substituídos modelos.
